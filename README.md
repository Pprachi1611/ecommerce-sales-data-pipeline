# E-Commerce Sales Data Pipeline

## Project Overview

A beginner-friendly data engineering project that
extracts e-commerce data from CSV files, transforms
and cleans it using Python, and loads it into
PostgreSQL.

## Technology Stack

- Python
- Pandas
- SQL
- PostgreSQL
- SQLAlchemy
- Git and GitHub

## Pipeline Architecture

CSV Files → Python ETL → Data Cleaning
→ PostgreSQL → SQL Analytics

Currently in development.
